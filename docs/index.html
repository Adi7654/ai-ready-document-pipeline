How it works

Every answer on this page was produced by a pipeline running in Databricks, then exported as static files: there is no server behind this site.

  1. Bronze → silver: 9,907 articles from the MLSUM dataset are cleaned, deduplicated (exact and MinHash near-duplicates), language-checked and given parsed dates; 9,722 remain.
  2. PII masking: e-mails, URLs, phone numbers and person names are replaced with placeholders such as [PERSON], verified by a blocking residual check and an LLM audit.
  3. Chunks and embeddings: 40,975 sentence-aligned chunks, embedded with a multilingual model and indexed in Databricks Vector Search.
  4. RAG: each question is searched per newspaper, an LLM checks each article is really on topic, then summarises each newspaper in English and compares them.
  5. This site: headlines were translated to English once (with a check that rejected 27% of first-pass translations for altering the masking placeholders), and "same story" links come from the similarity of article vectors across languages.

Code, design decisions and measured results: github.com/Adi7654/ai-ready-document-pipeline

About the data

Articles come from the MLSUM research dataset (one newspaper per language, mostly 2018–2019). It is licensed for non-commercial research; this site shows only headlines, short snippets and links to the original articles. Personal names are masked automatically, so some public figures appear as [PERSON], and a few names were missed by the model.
